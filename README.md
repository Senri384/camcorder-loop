# Camcorder Loop / 《炸弹密室》

手持摄像机式互动叙事密室原型。

这是一个完全本地运行的预制交互版本。运行时不调用 Gemini 或其他 LLM，也不需要 API Key。待机画面可以选择文字模式或视频模式；视频素材未完成的节点会自动回退到文字画面，不影响状态机和剧情推进。

## 运行

```powershell
npm start
```

打开 `http://127.0.0.1:5173/index.html`。

## 运行原理

- `story-content.js`：预生成剧情、NPC 回应、失败反馈、自动节点和循环文本库。
- `app.js`：把玩家自由输入归类为意图和目标，执行硬状态规则，再从对应情境中选取未重复文本。
- `video-manifest.js`：把剧情节点映射到可选视频素材，并记录素材是否已经完成。
- `assets/video/`：已经通过验收、可在网页内播放的视频片段。
- `assets/ui/`：以翻折 LCD 为主体的摄像机近景资源；机身保持真实比例并自然裁出右边界，LCD、实体键由 HTML 对齐覆盖，道具栏独立放在机身下方。
- `server.js`：只负责提供本地静态文件，没有模型代理路由。

剧情仍会按时间自动推进。玩家输入会中断当前自动节点计时，改变状态后重新安排后续节点；例如提前拦住 Sam，后续节点会改为检查防爆门，而不会再出现撞门结果。

情报跨循环保留，道具和房间状态在爆炸后复位。只有在线路、外壳、固定结构、控制室设备和液压孔都得到验证后，系统才会解锁完整逃生判断。

当前视频资产已经覆盖完整开场演示、全部主要自动节点、分层探索、道具反馈、爆炸循环重置和最终逃生。多个文本变体会复用语义相同的视频片段；未映射或加载失败的内容仍会安全回退到文字画面。
